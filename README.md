# Tourism and Travels

## Project Description

Tourism and Travels is a Python-based travel management project designed to help users explore and select travel packages for different destinations.

The project provides a simple menu-driven interface where users can choose tourism options and view relevant travel details.

## Features

- National and international tour options
- Destination selection
- Travel package details
- User-friendly menu-driven interface
- Booking-related options
- Simple console-based interaction
- MySQL database connectivity

## Technologies Used

- Python
- MySQL
- MySQL Connector
- SQL
